마지막 메시지 (강화판) - 실행 방법

1. ZIP 압축을 풉니다.
2. index.html 을 브라우저에서 엽니다. (assets 폴더와 같은 위치)
3. 시작 화면의 '게임 시작' 버튼을 누르면 50초 이내 플레이가 시작됩니다.

강화 내용
- 장면당 8초 제한 타이머 (시간 초과 = 망설임 → 방관 선택 처리)
- 실시간 '영상 조회수' 카운터: 선택에 따라 확산/차단
- 자동 진행 (다음 버튼 제거), 타자 효과, 채팅 순차 등장
- 화면 흔들림 · 경고 플래시 · 효과음 · 모바일 진동
- 엔딩 통계(플레이 시간, 최종 조회수, 결정 속도, 망설인 횟수)
- 선택지 하이라이트 버그 수정, 서연 설정 모순 수정(단체방 발언은 하은)

[추가] 엔딩 컷씬: 굿/배드 엔딩 진입 시 약 8초 컷씬 재생 (SKIP 버튼으로 건너뛰기 가능)

[추가] 세로 9:16 쇼츠 화면
- 450x800 고정 캔버스를 창 크기에 맞춰 자동 확대/축소 (어떤 화면에서도 9:16 유지)
- 녹화 팁: 브라우저 창을 세로(9:16)로 맞추거나, 폰 화면녹화(1080x1920)로 찍으면 꽉 찹니다
- 하단 약 8%는 쇼츠 제목/버튼 UI에 가려지는 안전영역으로 비워둠

[추가] 분위기/스토리 강화
- 어둠(비) → 새벽 → 햇살로 점점 밝아지는 배경 (좋은 선택은 더 밝게, 나쁜 선택은 어둡게)
- 이전 선택이 다음 장면 대사에 반영 (웃었으면 "너도 웃었잖아", 말렸으면 서연이 알아봄 등)
- 엔딩: 서연의 마지막 한마디, 선택 기록(●), 선택 이력 반영 문구

[추가] BGM (코드로 생성, 저작권 걱정 없음)
- 어두운 장면: 빗소리 + 낮은 단조 패드 + 쓸쓸한 음 / 밝아질수록 장조 + 맑은 종소리
- 해피 컷씬에서 해가 뜰 때 음악도 함께 밝아짐, 배드 컷씬은 어둡게 유지
- 시작 버튼을 누르면 재생 시작, 오른쪽 위 🔊 버튼으로 끄기/켜기

[변경] 대화 확장: 장면당 대사 4~5줄로 늘림, 장면별 제한시간 6초. 평균 플레이 약 38~40초(선택 포함, 컷씬 제외)

[변경] 시간제한 제거: 선택지를 직접 고를 때까지 기다림 (영상 조회수만 계속 올라감)

[추가] 5번째 장면 "복도 끝에서" (장면 3과 마지막 선택 사이). 총 5장면, 선택 플레이 약 45초 + 컷씬 약 8초

[쇼츠 50초 이내 맞춤] 대사/피드백/컷씬 속도를 압축. 장면당 2~3초 고민 기준으로 시작~엔딩 화면까지 약 40~45초

[추가] 아이패드 와이드 화면: 태블릿(터치 + 큰 화면)에서는 화면을 넓게 사용. 상단 📱 버튼으로 9:16 고정(쇼츠 녹화용) ↔ 와이드 전환, 선택은 기억됨

[추가] 로비 연출: 알림 배너(민수/지훈/하은)가 위에서 내려옴, 비+번개, 이미지 서서히 확대, 제목 글리치, 빛 입자, 시작 버튼 반짝임, 등장 애니메이션

[추가] 현실적인 메신저 UI: 채팅방 헤더("입력 중…"), 프로필 아이콘, 시간 표시, 읽음 표시(1), 동영상 카드, 이모지 반응, 시스템 알림,
선택하면 내 말풍선으로 전송되고 상대가 입력 중… 후 답장

[감동 강화] 서연의 '별 이야기' 복선→해피엔딩 회수, 선택 후 '속마음' 한 줄, 배드 컷씬(입력 중…이 사라지고 음악 침묵),
해피 컷씬(다시 발표해볼래, 맨 앞에서 들어줄래 + 선율), 문구 "마지막 메시지는, 첫 인사가 되었다 / 끝내 도착하지 않았다"

[녹화 모드] 주소 뒤에 ?rec=1 을 붙여 열기 (예: https://아이디.github.io/저장소/?rec=1)
- 처음(로비)부터 시작, 시작 버튼은 "● 녹화 시작"
- 대사 진행이 빨라짐(약 1.8배). 5장면에서 첫 선택(권장: 03 방관 → 배드엔딩 컷씬) 후
  "◀◀ REWIND / 같은 순간, 다른 선택." 되감기 연출로 5장면 복귀 → 두 번째 선택(권장: 01) → 해피엔딩 컷씬 → 엔딩 카드
- 엔딩 카드 문구(117/1388, AI 표기)는 index.html 의 id="endCard" 부분에서 수정

[녹화 모드 v2] 주소 뒤에 ?rec=1 (수동 진행은 ?rec=1&manual=1)
- 시작 버튼 → (PC 크롬/엣지: 화면 녹화 자동 시작) → 번개·글리치 로비 연출 2.5초 → 게임 자동 진행(터치 효과로 선택) → 배드엔딩 → 되감기 → 해피엔딩 → 엔딩 카드 → (PC) 자동 저장
- 아이패드/폰 브라우저는 웹에서 화면 녹화를 시작할 수 없음: 제어 센터 '화면 기록' 먼저 시작 → 시작 버튼
- 연출: 필름 그레인, 비네팅, 장면 시간 스팅어, 천둥/심장박동/별 파티클/유성, 나쁜 선택 글리치, 조회수 급등 표시
- 전체 길이 약 44초 (시작~엔딩 카드 3.6초 유지)

[팀명 RE:PLY] 녹화 모드 로비(시작 직후)와 엔딩 카드에 "TEAM RE:PLY" 표기 (Reply ↔ Replay 글자가 바뀌는 연출), 되감기 화면은 "◀◀ RE:PLAY"
- 팀명 변경: index.html 에서 "RE:PL" 로 검색해 3곳 수정 (rw-label 은 되감기 문구)
- 엔딩 카드 유지 시간 4.4초 → 전체 약 45초

[팀명 변경: RTR (REPLY TO RESCUE)] 로비(녹화 모드 시작 직후)와 엔딩 카드에 "TEAM RTR · REPLY TO RESCUE" 표기
- 엔딩 카드: RTR → R·T·R 이니셜이 빛나며 REPLY TO RESCUE로 펼쳐지고 "답장 한 줄이, 누군가를 구합니다." 표시
- 되감기 화면 문구는 "◀◀ REWIND"로 복구, 엔딩 카드 유지 4.8초 (전체 약 46초)
- 팀명 변경: index.html 에서 "RTR" 검색 (team-tag, team 블록)
